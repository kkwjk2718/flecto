# 권한·준비 승인 기록 양식

**이 문서의 존재나 체크박스는 사용자의 실제 승인이 아니다.** 현재 모든 항목 PENDING이다. 사용자 메시지·클라이언트 승인·공식 로그인 완료 같은 근거를 기록한다. 비밀 값은 쓰지 않는다.

| 범위 | 현재 | 근거/시각 | 허용할 실제 경로·한도 |
|---|---|---|---|
| 프로젝트 폴더 생성·수정 | PENDING | 없음 | 선택한 root 내부 |
| 필요한 프로젝트 패키지·시험 브라우저 | PENDING | 없음 | 확인된 registry·버전·다운로드 |
| 별도 OS/CLI 설치 | PENDING | 없음 | 공식 경로·필요 항목 |
| localhost 서버·합성 source 실행 | PENDING | 없음 | 확인한 loopback ports |
| 현재 개발 모델·서브작업 호출 | PENDING | 없음 | 승인 client/model/account |
| 제품 Codex 로그인·합성 probe | PENDING | 없음 | 전용 runtime, 사람이 로그인 |
| 선택 이미지 호출 | PENDING | 없음 | 승인 route와 횟수·예산 |
| 시연용 Chrome 프로필 | PENDING | 없음 | 개인 기본 프로필 제외 |
| 대회 사전 준비 범위 | PENDING | 없음 | 행사 안내의 허용 범위 |
| 추가 지출·새 provider | NOT_APPROVED | 없음 | 자동 진행 금지 |
| 외부 공개·제출 | NOT_APPROVED | 없음 | 마지막 사람 확인 |

## 승인 후 자동 진행 가능한 예시 문장

아래는 사용자가 실제로 선택해 말할 때만 효력이 생기는 예시다. 그대로 파일에 들어 있다고 승인으로 읽지 않는다.

```text
이 프로젝트 폴더 안에서 계획에 필요한 코드 작성·수정·로컬 테스트를 진행해.
확인한 필수 프로젝트 의존성과 테스트 브라우저 설치는 허용해.
현재 내가 선택하고 로그인한 개발 경로 안에서 작업하고, 추가 청구·계정·외부 배포는 하지 마.
필요한 로그인·OS 보안 확인은 묶어서 알려줘. 일반 구현 선택과 관련 버그 수정은 기록하고 계속해.
대회 사전 준비와 실제 개발의 허용 범위는 내가 확인한 안내를 따라.
```

범위를 바꾸는 새 권한은 이전 승인으로 유추하지 않는다. 단, 이미 승인한 동일 작업을 매번 재질문할 필요는 없다.
