# 시장 진입과 추후 발전 방향

**장기 계획은 후보이며, 확보한 고객·계약·출시 약속이 아니다.** 직전 발표 초안의 ‘검증 시장 → 도입 시장 → 확장 시장’과 ‘MVP → 사용자 적응 → 기관 도입 → 플랫폼화’ 구성을 유지하되 단계 진입 조건을 명시한다.

## 1. 시작 범위

처음부터 모든 사이트와 사용자를 지원하지 않는다. **구매 혜택 신청과 문화센터 강좌 신청처럼 입력·선택·동의·제출이 명확한 절차형 업무**에서 동작을 먼저 확인한다.

초기 체험자는 심사위원·참가자다. 고령자 중심 디자인이라는 방향과 실제 표본의 범위를 나눈다. 실제 고령자 평가와 기관 담당자 의견은 행사 이후 검증 과제로 남긴다.

## 2. 시장 진입 흐름

| 단계 | 대상·목적 | 할 일 | 다음 단계 진입 조건 |
|---|---|---|---|
| 검증 환경 | 두 가상 테스트 사이트·행사 참가자 | 원본 저장·구조 변형·오류·반복 사용 검사 | 검증 빌드·실패·제한사항을 재현 가능하게 기록 |
| 소규모 협업 | 학교·복지·교육·신청형 서비스를 운영하는 기관 후보 | 실제 반복 문의와 도입 책임 확인, 동의받은 제한 파일럿 설계 | 명확한 업무·담당자·지원 범위·데이터 처리 합의 |
| 반복 가능한 도입 | 검증한 유형의 여러 사이트 후보 | 템플릿·변경 감지·호환성 관리·운영 문서 | 사이트 변경 시 안전한 실패·유지 비용·효과 확인 |
| 플랫폼 후보 | 서비스 내장형 UI·SDK·화이트라벨 | 확장 외 배포 방식·API·버전·지원 설계 | 수요·정산·품질·권한 구조가 검증된 뒤 결정 |

대상 기관이 이미 고객이라고 표현하지 않는다. 금융·의료·실제 행정 제출 등은 앞 초안의 확장 예시지만, 현재 MVP에 포함되지 않으며 별도의 위험·인증·운영 검토가 필요한 먼 후보로 남긴다.

## 3. 제품 로드맵

### Phase 1 — 이번 MVP
Chrome 확장, 여섯 템플릿, 원본 DOM 연결, 두 사이트, 사용자 설정, 로컬 구조 캐시, 3초 안내·10초 종료·후원 카드, 실제/고정 응답 구분.

**완료 기준:** 기능 목록이 아니라 원본 결과·안전 검사·동일 빌드의 근거. 모든 기능을 끝내지 못하면 LIMITED 또는 SINGLE_SITE 등 실제 등급으로 표시한다.

### Phase 2 — 사용 경험과 호환성
고령자를 포함한 적절한 참여자와 평가하고 글씨·설명량·단계 수를 개선한다. 웹 유형을 늘리되 지원/미지원 범위를 유지한다. 사용자가 명시적으로 선택한 선호를 기억하는 것부터 강화한다.

‘반복 사용 행동을 자동 학습’하는 기능은 사용자 동의·데이터 최소화·안정성을 검토한 후속 후보다. 지금 MVP가 행동을 학습하고 있다고 말하지 않는다.

### Phase 3 — 기관 운영
기관별 업무 템플릿 관리, 사이트 변경 감지, 승인된 배포, 호환성 테스트, 문제 신고·복구 절차를 검토한다. 개인별 이동 경로를 무단 추적하는 분석 도구가 아니라 허용된 비개인 운영 지표를 우선한다.

**도입의 가치 가설:** 문의·작업 중단·지원 부담을 줄일 수 있는가. 실제 기관 데이터로 확인하기 전 절감액을 제시하지 않는다.

### Phase 4 — SDK·화이트라벨·다른 환경
브라우저 확장 외에 서비스 자체에 ‘쉽게 이용하기’ 기능을 넣는 SDK·화이트라벨을 검토한다. 모바일 웹·키오스크·공공 터치스크린은 별도 인터페이스와 권한·배포를 검증해야 하는 확장 후보다. Chrome 확장 코드를 그대로 설치하면 된다는 뜻이 아니다.

다국어·저시력·인지 지원 역시 대상별 실제 경험을 평가해야 한다. 큰 글씨만으로 모든 접근성 요구를 충족했다고 주장하지 않는다.

## 4. 기술 고도화 후보

| 후보 | 목적 | 채택 전 검사 |
|---|---|---|
| 더 많은 작업 템플릿 | 새로운 절차형 업무 표현 | 필수 정보·실행 의미·회귀 |
| 캐시·연결 구조 고도화 | 반복 처리 절약 | 최신 조건과 고지 보존, 실패·재생성 비용 |
| 안전한 시각 보완 | DOM의 시각 관계 부족 보완 | 개인정보 가림·10초 상한·실제 요소 연결 |
| 모델 최적화·전용 소형 모델 | 지연·비용 개선 가능성 | 적법한 데이터·같은 품질 기준·총비용 비교 |
| 기관 관리·리포트 | 지원·변경 관리 | 동의·데이터 최소화·통계 해석 |

자체 모델·강화학습·인프라 확대는 현장 필수 기능이 아니다. 검증된 입력–설계안 데이터가 확보되었다는 근거 없이 학습 계획을 현재 역량·성과로 바꾸지 않는다.

## 5. 로드맵 슬라이드 한 줄

> 두 절차형 서비스에서 정확한 동작을 확인한 뒤, 대상 사용자 검증과 기관 파일럿을 거쳐 서비스 내장형 인터페이스로 확장할 계획입니다.

## 6. 일정 표기

미정 월·분기별 매출·출시 날짜를 넣지 않는다. 단계명·다음 단계 조건·현재 위치를 표시한다. ‘향후 3개월 내 전국 도입’ 같은 약속은 대화에서 확정하지 않았다.
