# 모델 비종속 역할·도구 연결

## 역할을 먼저 정한다

| 역할 키 | 역할 | 최소 능력 |
|---|---|---|
| LEAD | 계약·배정·충돌 판단 | 명세 읽기, 코드 이해, 제한된 작업 계획 |
| IMPLEMENTER | 자기 모듈 구현 | 파일 편집·허용된 검사 실행 |
| REVIEWER | 독립 diff·요구사항 검토 | 읽기·근거 보고, 기본 읽기 전용 |
| QA | 재현·테스트 작성·검사 | 브라우저/원본 결과 검사 |
| UX_QA | 화면·IME·키보드 확인 | 실제 렌더 확인, 오류 재현 |
| RELEASE | 근거와 릴리스 정리 | 빌드·해시·보고서 판독 |
| PRODUCT_PLANNER | 제품 UI 연결 설계 | Codex 런타임, schema 출력, 제한 시간 |
| IMAGE_ASSET | 선택 에셋 | 승인 경로에서 실제 이미지 파일 반환 |

여러 역할에 같은 모델을 써도 된다. 실제 작업을 배정하기 전에는 전역 권한·클라이언트 실행 가능 상태를 확인한다. 작업표에서 E02가 직접 선행으로 적혀 있지 않다고 미승인 모델 호출을 허용하는 것은 아니다. 독립 세션 검토는 다른 관점을 주는 방법이지 완전 독립적인 정확성 보장은 아니다. 실제 테스트가 함께 필요하다.

## 개발 클라이언트 탐지

현재 사용자가 선택한 클라이언트와 모델을 우선 사용한다. CLI·앱에 지원되는 버전 조회·모델 선택·도움말을 읽는다. 출력에 실제 모델 ID가 없으면 `UNKNOWN`, 설정으로 요청한 ID는 `requested`, 반환에서 확인한 값은 `reported`로 구분한다.

자동 fallback·environment override·내장 worker 기본 모델이 있을 수 있으므로 설정과 실제 작은 시험을 함께 확인한다. 계정에서 호출할 수 없는 모델명을 지어내지 않는다. `ultra`, `max`, `ultracode`, 특정 CLI 플래그를 모든 클라이언트의 공통 기능으로 가정하지 않는다.

병렬 모드는 둘 중 하나만 소유한다.

- **NATIVE:** 실제 지원하는 서브에이전트/작업 공간 기능 사용. 리드가 생성 수와 작업 임대를 기록한다.
- **MANAGED:** 지원되는 비대화형 API/CLI를 검증한 최소 감독 프로그램이 실행한다. worker의 내부 재귀 생성은 끈다.

검증된 방법이 없으면 **SERIAL_SAFE**로 진행한다. 이것은 사용자가 모델을 바꾸는 것이 아니라 병렬성을 줄이는 안전한 실행 기본값이다. 채팅 종료 후 자동 복구는 검증되지 않았다고 남긴다. nested CLI 제한을 환경변수 삭제나 보안 옵션 해제로 우회하지 않는다.

## 선택적인 Claude Code 호환

루트 `CLAUDE.md`는 `AGENTS.md`를 import하는 호환점일 뿐이다. 공식 문서의 모델 상속·worktree·권한 기능을 사용할 때도 설치된 버전에서 확인한다. 이 패키지에는 모델명을 고정한 `.claude/agents`나 실행 hooks를 사전 설치하지 않았다. 필요할 때 승인된 범위에서 현재 도구 문법으로 생성한다. [S01–S04]

## 제품 Codex

제품은 기존 합의대로 Codex 런타임을 유지한다. 서버 측 TypeScript SDK를 기본 연결점으로 삼고, 모델 목록·schema 출력·취소·모달리티를 실제 확인한다. `model/list`가 제공되면 그 값을 기록하고, 목록에 없거나 호출이 거부되면 해당 경로를 차단한다. 개발에 사용한 모델과 제품 모델은 별도다. [S05–S06]

샘플은 공개 구조만 담은 8개 사례로 시작한다. 승인된 후보가 여럿일 때만 제한 비교한다. 필수 항목·동의·행동 연결 검증을 통과한 후보 중 실제 준비 지연을 보고 선택한다. 정확도를 떨어뜨려 3초 목표를 맞추지 않는다. 과금·실행 지원을 확인하기 전 대량 벤치마크를 돌리지 않는다.

## 모델 교체 절차

새 모델은 사용자 승인 집합 안에 있을 때만 선택한다. 모든 재배정은 새 attempt·lease로 만들고, 코드 계약과 QA는 유지한다. 제품 모델·프롬프트가 바뀌면 해당 실제 실행 근거와 캐시 버전을 무효화한다. 다른 회사·계정·API로 바꾸는 것은 별도 승인이 필요하다.

이미지 모델 변경이 개발 모델 변경을 뜻하지 않는다. 이미지 위임이 막혀도 기존 Codex 제품 런타임을 다른 서비스로 몰래 바꾸지 않는다.

## 미래에 기록할 model/capability lock

필드: role, client, requested_model, reported_model, version, auth_status(상태만), capabilities, timeout_support, parallel_mode, approved_scope, probe_evidence, checked_at. 예산은 `승인된 한도`와 `측정 가능한 사용량`을 따로 둔다. 구독 사용량을 계산 가능한 API 청구액처럼 단정하지 않는다.

공식 근거는 [sources/SOURCES.md](../sources/SOURCES.md)에서 읽는다. 외부 설명은 현재 사용자 계정의 설치·가용성 증거가 아니다.
