# 선택적 오프닝 영상 제작 명세

**분류: 기존 대화의 오프닝·예비 영상 아이디어를 정리한 선택 산출물. 현재 렌더된 영상이 없다.**

## 원칙

제품 연결과 검증이 먼저다. 영상은 이미 확보한 실제 화면·기본 도형·편집 가능한 문구로 제작한다. 장식용 영상 때문에 새 이미지·도구·과금 경로를 필수로 만들지 않는다. 제품이 미완성인데 완성된 UX 영상으로 대체하여 LIVE라고 보여주지 않는다.

## 60초 원안

| 구간 | 화면 | 자막·나레이션 | 자료 상태 |
|---|---|---|---|
| 0–8초 | 같은 크기의 메뉴·입력·동의 과정 카드 | 원하는 것은 신청 하나. 먼저 배워야 하는 것은 복잡한 메뉴. | 개념도 |
| 8–16초 | 가족 경험을 간단한 텍스트로 표시 | 가족의 구매 혜택 신청 도움 요청에서 출발했습니다. | 제공 전사의 경험 요약 |
| 16–25초 | FLECTO 이름과 사용자 목표 | AI가 화면을 준비하고, 사용자가 직접 결정합니다. | 브랜드·설계 |
| 25–42초 | 실제 검증 빌드의 입력·확인·원본 결과 캡처 | 필요한 입력과 선택을 큰 단계형 화면으로. | 캡처 확보 전에는 빈 자리 |
| 42–50초 | 현재 화면 계획 요청 차단 또는 구조 재사용의 실제 상태 | 준비된 화면은 검증한 연결로 조작합니다. | 실제 검증한 경우에만 |
| 50–57초 | 두 번째 사이트의 같은 템플릿 | 다른 사이트에서도 같은 방식으로. | 두 사이트 확인된 경우에만 |
| 57–60초 | 정적 마무리 | Don’t bend the user. Bend the interface. | 하단 ‘녹화 영상 / 실제 시연은 다음 화면’ |

## 결과가 부족할 때

실제 화면을 확보하지 못하면 25초 이후를 **‘구현 목표 · UI 개념도’**로 표시한다. 이런 영상은 기능 검증을 대체하지 않는다. 한 사이트만 확인했으면 두 번째 사이트를 완료된 장면처럼 넣지 않는다.

## 축약안

- **45초:** 문제 8초, 해결안 10초, 실제 동작 20초, 마무리 7초.
- **15초:** 이름·핵심 메시지·실제 Before/After 또는 명확히 라벨한 개념도.
- **무음판:** 핵심 내용은 자막으로 제공하고 빠른 글자 전환·깜박임을 피한다.

길이는 편집 목표이지 발표 공식 분량이 아니다. 3분 발표에 60초 오프닝을 무조건 넣지 않고 실제 데모 시간을 우선한다.

## 제작·출고 체크

검증 빌드의 화면만 캡처한다. 개인정보·저장된 비밀번호·사적 알림·토큰·실제 광고주 로고를 노출하지 않는다. 생성 이미지를 사용하면 장식·개념 자료임을 구분하고 사용자 후기처럼 쓰지 않는다. 다운로드·공개 업로드는 실제 파일과 승인된 채널이 있을 때만 수행한다. [발표 점검표](../evidence/02_PUBLISH_CHECKLIST.md)
