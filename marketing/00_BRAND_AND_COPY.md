# 브랜드·소개 문구 모음

**문구는 발표·홍보용 초안이다. 제품 완료·보편 지원·학습·실측 효과를 보장하는 문장으로 사용하지 않는다.**

## 공식 표기

- 프로젝트명: **Project FLECTO**
- 짧은 이름: **FLECTO**
- 기술 부제: **Adaptive Web Runtime**
- 메인 슬로건: **Don’t bend the user. Bend the interface.**
- 한국어 핵심: **사용자를 웹사이트에 맞추지 않고, 인터페이스를 사용자에게 맞춘다.**

이름은 앞 대화에서 ‘구부리다/방향을 바꾸다’의 라틴어 설명을 바탕으로 선택했다. 이번 패키지에서는 사전·상표·도메인을 새로 확인하지 않았다. 독점 상표권이나 등록 완료를 의미하지 않는다.

## 한 줄 소개

### 제품 중심
복잡한 웹사이트를 사용자가 직접 다룰 수 있는 단계형 화면으로 바꾸는 인터페이스.

### 개발 설명
기존 웹페이지의 구조를 해석해 공통 UI 템플릿에 연결하고, 원본 기능과의 일치 여부를 검증하는 브라우저 런타임.

### 사회적 목적
디지털 절차가 낯선 사용자도 필요한 내용을 확인하고 직접 진행할 수 있도록 돕는 것을 목표로 합니다.

## 길이별 소개

### 짧은 카드
**원하는 일만, 이해하기 쉬운 화면으로.**
큰 글씨와 큰 버튼, 단계별 입력으로 복잡한 웹의 사용 경험을 다시 구성하는 FLECTO.

### 약 150~250자 소개용 초안
Project FLECTO는 복잡한 웹사이트의 메뉴·입력·선택을 사용자의 목적에 맞는 단계형 화면으로 재구성하는 브라우저 확장 프로젝트입니다. 큰 글씨·큰 버튼·쉬운 설명을 중심으로 설계하며, 사용자는 직접 내용을 확인하고 제출합니다. 생성한 작업 구조는 원본과 대조한 뒤 재사용하는 것을 목표로 합니다.

### 약 1분 설명용 초안
FLECTO의 출발점은 가족이 온라인 구매 혜택 신청을 어려워해 도움을 요청한 경험입니다. 단순히 설명을 더하는 대신, 필요한 입력과 선택이 보이는 새로운 화면을 만들고자 합니다. AI는 현재 페이지에 맞는 짧은 연결 계획을 만들고, 실제 조작은 검증된 코드로 원본 서비스에 연결합니다. 이번에는 구매 혜택 신청과 문화센터 강좌 신청을 대상으로 원본 결과와 반복 사용을 검증합니다. 광고·후원은 비용 지원을 위한 가설이며, 현재는 시연용 카드로 계획하고 있습니다.

## 결론 문구 3안

1. **복잡한 메뉴 대신, 필요한 선택에 집중할 수 있도록.**
2. **AI가 화면을 준비하고, 사용자가 직접 결정합니다.**
3. **사용자가 웹사이트에 적응하는 대신, 인터페이스가 사용자에게 맞춰지도록.**

## 비전용 문구의 사용 범위

‘웹사이트가 사용자를 배우게 하자’는 제목에 사용할 수 있지만, 본문에서 현재는 사전 표시 설정과 작업 구조 재사용임을 설명한다. ‘누구나 모든 웹을 쓴다’는 보편적 효능 보장 대신, 지원 범위에서 개선을 검증한다는 표현을 쓴다.

## 시각 방향

기존 UI 선택과 같은 밝은 배경·짙은 글씨·파란 강조를 사용한다. 기술 상태 라벨은 색만이 아니라 글자로 표시한다. 가족·고령자 이미지가 없으면 도식·실제 화면으로 설명하고, 생성한 인물 이미지를 실제 사용자 후기나 인터뷰처럼 제시하지 않는다. 큰 타이포그래피와 실제 Before/After를 우선한다.

읽어야 하는 글자는 생성 이미지 안에 넣지 않고 편집 가능한 텍스트로 둔다. 차트 수치와 상태 라벨도 이미지 생성 모델에 맡기지 않는다.
