# 보험금 청구 시연

온담보험 시연센터는 로컬 가상 서비스다. 실제 보험 청구·계약·보험금 지급은 하지 않는다. 실제 개인정보 대신 아래 합성 값만 쓴다.

## 준비

Node 24에서 `npm ci`, `npm run build`, `npm run demo:start -- --live`를 실행한다. LIVE는 기존 Codex 로그인과 지원 CLI가 필요하다. 인터넷 문제 대비용 `npm run demo:start`는 FIXTURE라고 명시한 별도 실행이며 AI 성공으로 소개하지 않는다.

Chrome `chrome://extensions` → 개발자 모드 → 압축해제된 확장 프로그램 로드 → 이 프로젝트의 `dist/extension`. 확장 메뉴에서 FLECTO를 고정한다. 옵션의 도우미 주소와 연결 토큰은 로컬 `.flecto/demo/connection.txt`에서 넣는다. 이 파일과 토큰은 공유하지 않는다.

`http://127.0.0.1:4173/login`에서 `demo` / `flecto2026!`로 로그인한다. 이어 `http://127.0.0.1:4173/insurance/apply`를 연다.

## 시연용 입력

| 항목 | 합성 값 |
|---|---|
| 보험증권번호 | INS-2026-001 |
| 청구인 이름 | 김하늘 |
| 휴대전화 번호 | 01012345678 |
| 진료일 | 2026-09-01 |
| 청구 유형 | 통원 |
| 의료기관명 | 시연의원 |
| 청구 금액 | 85000 |
| 수령 은행 | 시연은행 |
| 예금주 | 김하늘 |
| 계좌번호 | 1002003004 |

## 3분 진행

1. 원본의 작은 글씨·많은 메뉴·여러 입력란을 보여준다.
2. 도구 막대의 FLECTO를 한 번 누른다. 보험 시연처럼 본문의 입력 폼이 하나면 쉬운 화면을 바로 준비한다. 여러 작업이 있는 화면에서는 `청구 내용 확인` 작업을 고른다.
3. 큰 입력란과 옆의 `여기에 입력하세요` 안내를 보여주며 값을 입력한다. 입력 단계가 길면 스크롤해서 나머지 항목을 채운다.
4. 청구 유형과 은행을 직접 선택하고, 두 동의 항목의 설명을 읽고 직접 체크한다.
5. 입력 내용 검토 → 원본 확인 화면 → 최종 직접 제출을 차례로 진행한다. 제출은 자동으로 재시도하지 않는다.
6. 접수번호를 보여준다. 이는 가상 서비스 원본 서버의 저장 결과이며, 실제 보험 심사·지급 완료가 아니다.

`원래 화면 보기`로 입력이 실제 원본에 반영된 모습도 확인할 수 있다. 오류가 나면 원래 화면으로 돌아가 원본의 안내를 확인한다. 준비 중 화면을 광고 때문에 늦추지 않는다.

## 발표에서 구분할 것

자동화 회귀 검사, 실제 AI LIVE 검사, 사람이 Chrome을 조작한 시연 기록을 구분한다. 실제 대기시간과 사용자 효과를 측정하지 않았다면 속도·완주율을 성과처럼 말하지 않는다. 범용 모든 보험사 지원은 아직 검증하지 않았다.
