# 제품 애플리케이션 영역

`extension`, `planner`, `demo-benefits`, `demo-culture`를 구현했다. 루트에서 `npm ci`, `npm run build`, `npm run demo:start`로 실행한다. 기본 계획 방식은 FIXTURE이며 실제 Codex는 `-- --live`로 구분한다. 설치·연결 순서는 [README](../README.md)를 따른다.

자세한 경계는 [아키텍처](../spec/01_ARCHITECTURE.md)와 [구현 계획](../IMPLEMENTATION_PLAN.md)을 따른다.
