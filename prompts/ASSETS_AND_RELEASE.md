# 선택 이미지·문서·릴리스 역할

## 에셋

실제 UI에 필요한 에셋만 요청한다. 이미지 클라이언트·모델은 실제 승인 경로를 확인해 사용하고 특정 이름을 기본으로 지어내지 않는다. 이미 승인한 Codex 이미지 경로를 활용하는 계획은 유지한다. 이미지 작업자는 코드·토큰·원본 사용자 데이터를 받지 않는다.

목적·규격·스타일·텍스트금지·참조·출력형식·기한을 request에 적는다. 정상 이미지 파일인지 decode·크기·실제 화면 적용을 확인한다. 설명이나 프롬프트를 반환한 것은 이미지 제작 완료가 아니다. 출력 파일은 integrator만 승인 에셋 폴더로 옮긴다.

생성1+필요수정1 출발 상한. 13:30 이후 새 요청하지 않고 14:45 이후 자동반영하지 않는다. 실패하면 기본 도형·텍스트로 진행한다. 이미지 생성과 제품 UI 생성은 다른 기능이다.

## 문서와 릴리스

발표 대본은 원본처리·같은UI두사이트·추가AI차단·무효화의 실제 장면에 맞춘다. 성능·매출·사용자효과 자리에는 측정 기록만 넣고 없으면 미확인으로 남긴다. 영상은 REPLAY이며 실제 LIVE 기록과 분리한다.

릴리스는 동일 artifact의 source/모델/검사/근거를 묶는다. 비밀 파일·프로필·로그를 포함하지 않는다. unsafe past green은 제외한다. FULL/SINGLE/FIXTURE/UNVERIFIED와 ops/manual/vision capability 상태를 모두 밝힌다. submitted는 실제 외부 제출 확인 없으면 false다.
