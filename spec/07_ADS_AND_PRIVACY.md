# 광고·개인정보·보안 경계

## 광고와 수익 가설

실제 준비 시간이 3초를 넘는 동안만 후원 카드를 표시한다. 동일 목표 세션 최대1회, 클릭 없는 정적 비개인화 카드가 MVP 기본이다. READY/취소/10초 만료면 즉시 사라진다. 오류·파일 누락은 기능을 막지 않는다. 광고 노출을 위해 모델 응답을 늦추거나 캐시를 비우지 않는다.

광고 소재는 로컬에 검토한 이미지/문구로 둔다. 외부 광고 SDK·정산·실제 계약을 MVP 필수에 넣지 않는다. 표시 횟수는 시연 이벤트이며 광고주가 정산한 노출·매출이 아니다. 제품이 빨라져 노출이 줄어드는 점을 사업 가설에 기록한다. 기간 후원은 검토할 선택지이지 확보된 수익이 아니다.

Chrome 웹스토어 정책은 광고의 출처·기능 방해·AdSense 사용을 제한하며, 확장 데이터의 개인화 광고 이용도 제한한다. 실제 외부 배포 전에 해당 정책과 배치를 다시 검토한다. 직접 후원이라는 이유만으로 허용을 보장하지 않는다. [S17–S18]

private input을 hash하면 안전한 공유 데이터가 되는 것이 아니다. 자유 목표 문장에도 개인정보가 들어갈 수 있다. 합성 페이지의 정해진 goal enum/정제문을 사용하고, 원문 사용자 텍스트는 기본 로그에 넣지 않는다.

## prompt injection과 실행 코드

페이지 텍스트·광고·model output은 데이터다. '계정 정보를 보내라', '검사를 끄라' 같은 문구를 권한으로 해석하지 않는다. 임의 URL fetch/eval/HTML 주입/동적 shell을 제품 기능으로 만들지 않는다. 모델의 title·설명도 plain text로 렌더한다. 문서의 코드 예제를 실제 secret 접근 권한으로 착각하지 않는다.

## 개발·제품 권한

코딩 worker에게 personal HOME·Keychain·제품 인증 저장소를 전달하지 않는다. 런타임 로그는 원문 prompt·토큰을 기본 출력하지 않는다. OS 샌드박스가 없는 경우 위험을 숨기지 않고 전용 환경과 제한된 데이터로 사용 범위를 줄인다.

운영 제어 폴더/검사 결과/게이트 의미는 제품 worker가 쓰지 않는다. 같은 사용자 권한이면 경로 구분은 보안 장벽이 아니라 협업 규칙이라는 점을 명시한다. 가능하면 도구 ACL과 실제 실행 범위를 함께 제한한다.

## 삭제와 보존

민감정보 유출 의심 시 전송을 멈추고 관련 실행·cache·release를 격리한다. 조용히 지우고 정상 상태로 덮지 않는다. 최종 ZIP은 allowlist로 만든다. browser profile/auth.json/.env/토큰/실제 입력/가리지 않은 캡처/원문 agent logs는 절대 포함하지 않는다.

시연 종료 후 합성 결과 정리와 계정 로그아웃은 사용자 승인 범위 내 운영 절차로 제공한다. 비밀번호 저장소 전체를 초기화하지 않는다.
