# 제품 명세 — 현재 구현 기준

## 한 문장
FLECTO는 원본 웹사이트의 기능을 사용자가 직접 수행할 수 있도록, 현재 작업에 필요한 요소를 여섯 공통 템플릿에 연결하고 검사한 뒤 보여주는 Chrome 확장이다. 최초 구조 해석에는 Codex를 쓰고 준비된 현재 화면의 반복 조작은 일반 코드로 처리한다.

## 사용자 흐름

첫 실행 설정(글씨/대비/설명량) → 원본 사이트 로그인 → FLECTO 활성화 → 원본에서 확인한 큰 작업 버튼 또는 다른 목표 입력 → 연결 준비 → 입력·선택 → 안내·동의 → 실제 값으로 검토 → 사용자가 원본 제출 동작 실행 → 원본 결과 확인.

원본 로그인은 Chrome 저장 테스트 계정을 사용한다. FLECTO가 비밀번호를 자동 추출하는 기능이 아니다. 시연 프로필은 개인 프로필과 분리한다.

## 지원 범위

일반 HTML의 input/textarea/select/checkbox/radio/button/a, 같은 출처의 메뉴 이동, 검증한 React controlled input, SPA와 full-navigation, 읽을 수 있는 공개 안내·선택지가 대상이다.

file/password/OTP, 결제, CAPTCHA, 접근 불가능한 cross-origin iframe, closed Shadow DOM, canvas-only 조작, trusted event를 필수로 요구하는 동작은 지원 성공을 주장하지 않는다. 그런 상황에서는 원본을 제시한다. 시각 보완으로 없는 DOM 대상이나 권한을 만들어낼 수 없다.

## 필수 기능과 수용 관점

| 기능 | 수용 관점 |
|---|---|
| 큰 작업 버튼 + 자유 목표 | 현재 실제 링크/버튼에 연결; 아직 보지 못한 전체 흐름을 지어내지 않음 |
| 여섯 템플릿 | 작업선택/입력묶음/항목선택/안내동의/최종확인/결과 |
| 사전 설정 | 값 저장 후 결정적 스타일로 적용; 추가 LLM 요청 없음 |
| DOM 연결 | 입력과 버튼은 실제 source handler를 거침; 서버 저장을 우회하지 않음 |
| 구조 재사용 | 새 문서 요소에 고유 재연결; 조건 불일치면 무효화 |
| 3초 목표/30초 대기 상한 | 2026-09-29 16:07 사용자 지시로 기존 10초 상한 연장. 실제 조작 가능까지 측정; 로딩 shell만 먼저 뜬 것은 완료 아님 |
| 준비 광고 | 실제 3초 초과 준비에만 노출; 기능 완료 시 즉시 종료 |
| 오류·원본복귀 | 입력/동의 보존을 명확히 하며 조용한 실패·거짓 성공 금지 |
| 두 사이트 | 구매 혜택 기본+구조변형 후 문화센터로 확장 |
| 관찰·측정 | 입력과 개인정보가 아닌 상태·시간·모드·결과만 기록 |

## 바꾸지 않을 안전 원칙

AI 생성 HTML·JavaScript를 실행하지 않는다. 원본 필수 정보와 동의를 감추지 않는다. 사용자의 최종 클릭 전 자동 신청하지 않는다. 본인이 선택한 것과 AI가 추천한 것을 섞지 않는다. 로그인 화면은 분석·캡처하지 않는다. 실제 데이터는 브라우저 안에서 원본에 반영하며 모델·공유 캐시·광고·아카이브로 보내지 않는다.

## 차별점 검증

같은 화면에서 AI 계획 경로만 차단하고 입력 수정·선택·제출을 수행한다. 원본 서버와 인터넷 전체를 끄는 시험이 아니다. 두 사이트를 같은 템플릿으로 다룬다. 필수 항목을 변경하면 기존 연결을 거부한다. 원본 결과가 실제 저장되었는지 QA가 확인한다.

'다른 에이전트에는 확인·캐시가 전혀 없다'고 주장하지 않는다. FLECTO가 어떤 구조를 채택했고 어떤 동작을 실제로 검사했는지를 보여준다. 참가자 체험은 고령자 검증 효과로 일반화하지 않는다.

## 완료 정의

전체 완료 목표는 두 사이트의 원본 저장, B 변형, 준비 후 추가 추론 없는 현재 화면 조작, 필수 안전 기능, 접근성 동작, 실제 Codex 흐름이다. 부분 실패 시 정상 단일 사이트를 보존하되 FULL이라고 표시하지 않는다. 아무것도 실행하지 않고 원본으로 돌려보내는 것만으로 기능 성공률을 높이지 않는다.
