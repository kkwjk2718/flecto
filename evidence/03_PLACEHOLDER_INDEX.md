## 공통 입력 원칙

`RUN_ID`, `SOURCE_SHA`, `ARTIFACT_HASH`, `MODEL_LOCK`은 실제 기록을 사용한다. 성공·실패·전체 시도는 같은 표본을 사용한다. DEMO_MODE는 화면과 일치해야 한다. 참여자 구성·고령자 여부는 실제 관찰의 범위이며 추론하지 않는다. 광고 노출과 계약 매출을 구분한다.

[결과 입력 양식](01_RESULTS_TEMPLATE.md)과 [발표 점검](02_PUBLISH_CHECKLIST.md)을 함께 사용한다.
